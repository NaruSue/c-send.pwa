# c-send PWA

よく使う文章を登録し、必要なときにコピーできるPWAです。テンプレートは端末に保存でき、接続先を選んでアカウントと同期することもできます。

- [正式PWAを開く](https://narusue.github.io/c-send.pwa/)
- [カスタムAPIサーバ用API仕様](custom-api-server-spec.md)：自分や組織のサーバを接続先として使うメリット、入口API、認証、CORS、保存・同期API、AI向けサーバ作成プロンプト
- [接続先定義・お知らせ仕様](connection-spec.md)

カスタムAPIサーバは「接続先一覧」で入口URLを指定し、そのサーバのユーザーでログインして追加します。自動同期の許可と、テンプレートごとの同期選択は別々に行います。公開JSONの参照だけなら「URLを参照」を使います。

公式とカスタムを区別し、実際のドメインを表示します。カスタム接続への初回送信では、送信先と運営者が本文を閲覧できることを確認します。接続確認の成功は運営者の安全性を保証しません。

カスタム接続の機密情報に関する注意（関連付け、パスワード用途、個人情報、公開情報・ダミー情報の扱い）は、[利用上の注意：機密情報](custom-api-server-spec.md#利用上の注意機密情報)にまとめています。c-send PWAはパスワード管理サービスではありません。

実際の秘密情報を扱う場合の社内LAN・VPN限定運用、専用クライアント、HTAの注意点は、[機密情報を扱う場合の運用境界](custom-api-server-spec.md#機密情報を扱う場合の運用境界)を参照してください。

APIサーバの実装言語や設置先は自由です。仕様書と作成プロンプトをAIへ渡して実装を進められます。認証・所有者確認・CORSを含む動作確認を行ってから利用してください。

同期はPWAの起動時、保存時、画面への復帰時、通信復帰時、起動中の定期確認で実行します。通信できない間の変更は端末に保存し、次の同期を待ちます。PWAを閉じている間の同期は保証されません。公式とカスタムの接続を同時に利用でき、保存先はテンプレートごとに選びます。

カスタム接続では、公式サイトへのログイン引き継ぎ、公式のクラウドバックアップ、管理者診断送信は利用できません。

## 鍵付きタグ

タグ名の先頭に `@` を付けると、端末の認証後に表示できます。タグ一覧のハートの鍵から、端末ごとに認証を登録・解除します。操作しないと初期設定の5分で再ロックされ、メニューの「鍵付きタグの設定」で1・3・5・10・15・30分に変更できます。画面を離れたときや鍵ボタンをもう一度押したときも再ロックされます。指紋・顔・PINなど、実際の認証方法は端末とブラウザーによって異なります。

この機能はPWAの画面上での閲覧・操作を制限するもので、保存データは暗号化されません。同期先の管理画面や書き出したバックアップにはロックが適用されません。パスワードや個人情報などはご自身の判断で管理してください。認証の登録は利用するURLごとに必要です。

## ビルドとテスト

Node.js 22で `npm ci` と `npx playwright install chromium` を実行した後、`npm run build` で配信用の `dist/` を生成し、`npm test` でブラウザーと同期のテストを実行できます。独自サーバー連携のHTTPSテストにはPythonの `cryptography` も必要です。GitHub Actionsはpushとプルリクエストで実行し、Pagesの配信前にも同じビルドとテストを通します。
